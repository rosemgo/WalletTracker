# WalletTracker: dashboard

La dashboard di WalletTracker, scritta in Angular. Usa le API REST del backend (`../backend`).

La guida passo passo è in [`docs/12-fase-2-passo-2-dashboard-angular.md`](../docs/12-fase-2-passo-2-dashboard-angular.md).

```bash
npm install                  # installa le dipendenze (la prima volta)
npm start                    # avvia la dashboard su https://localhost:8443 (il backend deve essere acceso)
npm test -- --watch=false    # esegue i test una volta
npm run build                # compila la versione di produzione in dist/
```
