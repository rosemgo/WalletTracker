# Sicurezza

WalletTracker gestisce dati bancari: la sicurezza ha la precedenza su qualsiasi altra funzione.

## Segnalare una vulnerabilità

**Non aprire una issue pubblica.** Usa la funzione di GitHub *Security → Report a vulnerability*
(segnalazione privata) di questo repository, descrivendo:
- cosa hai trovato e in quale versione (commit);
- come riprodurlo;
- l'impatto che ti aspetti.

Riceverai una risposta il prima possibile. Una volta corretta, la vulnerabilità verrà descritta
pubblicamente, con il tuo nome se lo desideri.

## Il modello di sicurezza

Le scelte, le protezioni attive e quelle pianificate sono descritte in
[`docs/17-sicurezza.md`](docs/17-sicurezza.md).
